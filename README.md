# 陈昊铭 · 我的中心

一个**单文件**的个人主页：没有框架、没有构建步骤、没有第三方依赖，所有 HTML / CSS / JavaScript 都写在 `index.html` 里，双击就能打开。

页面里带一个「游戏厅」，里面有四款可以直接玩的小游戏：

| 游戏 | 类型 | 技术 | 本地存档键 |
| --- | --- | --- | --- |
| 🐍 贪吃蛇 | 街机 | Canvas 2D | `chm-snake-best` |
| 🧱 打砖块 | 街机 | Canvas 2D | `chm-breakout-best` |
| 🃏 记忆翻牌 | 记忆 | DOM + CSS 3D | `chm-memory-best` |
| 🔢 2048 | 益智 | DOM | `chm-2048-best` |

## 快速开始

### 本地打开

直接双击 `index.html`，用浏览器打开即可。所有功能（包括最高分存档）在 `file://` 下都能正常工作。

想用本地服务器预览（更接近线上环境）：

```bash
# 任选一种
python -m http.server 8000
npx serve .
```

然后访问 <http://localhost:8000>。

### 发布到 GitHub Pages

1. 把 `index.html` 推到仓库根目录（仓库名一般是 `<用户名>.github.io`）；
2. 打开仓库 **Settings → Pages**；
3. Source 选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存；
4. 等一两分钟，访问 `https://<用户名>.github.io/`。

因为只有一个文件，不需要任何构建配置。


滚动时的彩色进度条固定在顶部；各区块进入视口时会淡入。

### 游戏厅的界面约定

- **左侧棋盘区**：四块棋盘叠放在同一个位置，同一时间只显示一块；
- **右侧面板**：分数 / 最高分、操作说明、方向键（仅贪吃蛇）、暂停与重新开始；
- 切换标签时，正在运行的游戏会自动暂停，切回来可以继续；
- 棋盘滚出屏幕或切到后台时也会自动暂停。

## 游戏规则

### 🐍 贪吃蛇

- 棋盘 18 × 18；
- 吃到食物 +10 分，身体长一节；
- 每累计 30 分，速度提升一档（步进间隔 145 ms → 最快 72 ms）；
- 撞墙或咬到自己即结束；
- 手机可以在棋盘上滑动，也可以用右侧方向键。

### 🧱 打砖块

- 8 列 × 5 行，共 40 块砖，每块 +10 分；
- 初始 3 条命，球掉出底部扣一条；
- 打光全部砖块进入下一关，球速 ×1.06（上限 8.4）；
- 击球点越靠挡板边缘，反弹角度越斜；
- 鼠标移动、触屏拖动、← → 或 A D 都能控制挡板。

### 🃏 记忆翻牌

- 4 × 4 共 16 张牌，8 对图案；
- 每次翻开两张：相同则保留，不同则自动翻回；
- 每翻开一组算一步，全部配对即获胜；
- 记录的是**最少步数**（越低越好）。

### 🔢 2048

- 4 × 4 棋盘，方向键 / WASD / 滑动移动；
- 相同数字相撞合并，得分等于合并出的数字；
- 目标合成 2048，达成后可以选择继续挑战；
- 没有空格且相邻数字都不相同则结束。

### 加一款新游戏

1. 在 HTML 里加一个棋盘容器：`<div class="board" data-game="你的id" hidden>…</div>`；
2. 在 `.tabs` 里加一个按钮：`<button class="tab" data-game="你的id">…</button>`；
3. 在脚本里照着 `init2048` 的样子写一个 IIFE，实现 `reset / begin / showState / key`；
4. 把它塞进 `games` 对象，并在 `PANELS` 里补一条面板配置；
5. 完事——标签切换、暂停、重开、计分面板都会自动接上。

## 技术实现

### 结构

- **一个 IIFE 包住所有脚本**，不污染全局；
- **统一游戏框架**：每款游戏暴露 `reset() / begin() / pause() / showState() / key()`，公共代码负责标签切换、面板、键盘路由；
- **一个 `requestAnimationFrame` 循环**：每帧只驱动当前激活的游戏，其余游戏不消耗 CPU；
- **画布用逻辑坐标**：贪吃蛇按 360×360 绘制、打砖块按 480×480 绘制，再按设备像素比缩放到实际尺寸，因此不会模糊；
- **状态机**：`running / over / started` 三个布尔量决定覆盖层显示什么。

### 存档

四个最高分都存在 `localStorage`，键名见文首表格。读写都包在 `try / catch` 里，无痕模式下会自动跳过存档而不会报错。

### 动效

| 效果 | 实现 |
| --- | --- |
| 背景光晕漂移 | CSS `@keyframes` + `filter: blur()` |
| 标题流光 | `background-clip: text` + 背景位移 |
| 打字机 | `setTimeout` 逐字追加 |
| 滚动淡入 | `IntersectionObserver` |
| 顶部进度条 | `scroll` 事件 + `width` 百分比 |
| 卡片跟随光斑 | `pointermove` 写入 CSS 变量 |
| 翻牌 | CSS `transform: rotateY()` + `preserve-3d` |
| 吃食粒子 | 手写粒子数组，逐帧更新 |

所有动画都遵守 `prefers-reduced-motion: reduce`，系统开启「减少动态效果」时会自动关闭。

### 性能

- 只有当前游戏参与逐帧计算；
- 画布按 `devicePixelRatio` 渲染，上限 2 倍，避免高分屏下过度绘制；
- `ResizeObserver` 只在棋盘尺寸变化时重设画布，不做轮询；
- 粒子数量很少（一次 12 个）且会自然衰减。

## 常见问题

**Q：最高分没了？**
A：最高分存在浏览器的 `localStorage`。换浏览器、换设备、清缓存、无痕模式都会「丢」，这是预期行为。

**Q：键盘按了没反应？**
A：需要先让棋盘获得焦点——点一下棋盘区域即可。手机上点一下画布同样有效。

**Q：为什么只用一个文件？**
A：方便——下载、复制、托管都只要一个文件。代价是文件比较长（约 2000 行），可以按上面的「自定义指南」用搜索定位。

**Q：有声音吗？**
A：没有。整站 0 个音频文件，避免自动播放策略带来的麻烦。

**Q：手机上能玩吗？**
A：可以。四款游戏都支持触屏：贪吃蛇和 2048 用滑动，打砖块用拖动，记忆翻牌用点击。
